## Description (392 / 400 characters)

Witch-finding advice straight from the Malleus Maleficarum (1486), in Summers' 1928 translation, each quote linked to its page on archive.org. Stolen members in bird nests, hailstorms, knife-milking. Historical text, dark comedy, not endorsement. Admins use /setup to set filters per category (off/mild/full) or pick a preset, so your server decides how grim it gets. Try /accuse on a friend.
