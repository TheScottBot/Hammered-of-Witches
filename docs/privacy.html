Privacy Policy

Last updated 17 October 2026

The short version: the bot doesn't store anything about you.

What it never collects

  • Your messages. It only answers slash commands, and never asks Discord for access to what's said in chat.
  • Who you are. No user IDs, usernames or profiles are saved, including who ran a command or who got /accused.
  • What you searched for. What you type in /hammered about: is used to find a passage and then forgotten.

What it does keep

Only each server's choices, and only for servers that change them with /setup:

  • the server's ID;
  • its filter levels (for example, "gore: mild");
  • the IDs of any passages it has hidden.

These are deleted when a server admin runs /setup reset, or when the bot is removed from the server.

While it's running

Discord sends the bot what it needs to answer a command: the command, its options, and the server, channel and user it came from. The bot uses that to reply and doesn't save it. To avoid repeating itself, it remembers the last few passages shown in each server (or DM) in memory only; that's gone whenever the bot restarts.

Its log records which command ran and in which server (by ID), plus any errors, so problems can be fixed. Logs don't include who ran a command or what they searched for, and old logs are overwritten as new ones are written.

Sharing

Nothing is sold or shared with anyone. The only other party involved is Discord itself, under Discord's Privacy Policy.

Changes and contact

If this policy changes, this page will say so. Questions, or want something deleted? Open an issue on GitHub.
